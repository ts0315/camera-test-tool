# 📷 摄像头测试工具 (Camera Test Tool)

一款功能强大的在线摄像头测试工具，支持多分辨率、帧率调节、录制、拍照等功能，完全在浏览器端运行，无需安装任何软件。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📷 **多分辨率支持** | 4K / 2K / 1080P / 720P / 480P / 240P |
| ⚡ **帧率调节** | 60 / 30 / 15 / 10 fps |
| 📹 **多摄像头切换** | 自动检测并切换所有可用摄像头 |
| 🎤 **麦克风切换** | 自动检测并切换所有可用麦克风 |
| 📸 **拍照截图** | 一键拍照，自动下载带时间戳的PNG图片 |
| 🔴 **视频录制** | 录制含声音的视频，自动下载WebM格式 |
| 🔊 **有声/静音切换** | 一键静音/取消静音 |
| ⛶ **全屏模式** | 全屏显示摄像头画面 |
| 📊 **音量可视化** | 实时音量柱显示，直观查看音量大小 |
| 📊 **实时帧率** | 实时显示当前帧率(fps) |
| ⏱️ **录制时长** | 录制过程中实时显示已录制时长 |
